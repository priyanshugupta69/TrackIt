# Multi-Dimensional Planning & Tracking Tool

A web application built for project planning and employee tracking.\
It helps teams organize projects, assign tasks, and monitor progress
from a single place.

## Overview

This tool allows teams to:

-   Manage multiple projects
-   Assign tasks under projects
-   Track which employee is working on which task
-   Monitor overall progress of work

## Features

-   Project creation and management
-   Task assignment and tracking
-   Employee workload visibility
-   Centralized view of ongoing work

## Purpose

To keep project planning and employee task tracking simple, organized,
and easy to manage.
